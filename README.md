# Photo Candidate Picker

Локальное Flask-приложение для подбора фото-кандидатов к статьям через Wikimedia Commons API.

## Возможности

- загрузка Excel/CSV через браузер;
- обязательные колонки: `title`, `search_query`, `category`, `exact_name`, `must_include`, `must_exclude`, `notes`;
- поиск изображений в Wikimedia Commons;
- сохранение найденных изображений в `images/[slug]`;
- галерея с крупными карточками;
- отображение источника, автора и лицензии;
- предупреждения по точности на основе `exact_name`, `must_include` и `must_exclude`;
- фильтр по темам (`category`);
- экспорт отчета `output/photos_report.xlsx`.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

На Windows используйте:

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

```bash
python app.py
```

Откройте приложение в браузере:

```text
http://127.0.0.1:5000
```

## Формат входного файла

Поддерживаются `.xlsx`, `.xls` и `.csv`. В файле должны быть колонки:

| Колонка | Назначение |
| --- | --- |
| `title` | Название статьи. Используется для папки `images/[slug]`. |
| `search_query` | Поисковый запрос для Wikimedia Commons. Если пусто, используется `title`. |
| `category` | Тема для фильтрации в галерее. |
| `exact_name` | Точное имя/объект, который должен встречаться в названии или метаданных. |
| `must_include` | Термины, которые должны встречаться в названии или метаданных. Разделители: запятая, точка с запятой или `|`. |
| `must_exclude` | Термины, наличие которых вызывает предупреждение. Разделители такие же. |
| `notes` | Внутренние заметки, отображаются в карточке и отчете. |

## Как работать

1. Подготовьте Excel/CSV по указанному формату.
2. Запустите приложение командой `python app.py`.
3. Откройте `http://127.0.0.1:5000`.
4. Загрузите файл через форму.
5. Проверьте карточки, авторов, лицензии, источники и предупреждения.
6. Скачайте отчет кнопкой **Скачать photos_report.xlsx**.

## Важное замечание

Предупреждения помогают быстро отсеять сомнительные результаты, но не заменяют ручную проверку соответствия изображения статье и условий лицензии перед публикацией.
